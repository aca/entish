NAME

entish - scripting language and interactive shell for my next 10 years

DESCRIPTION

The shell is the entry point to all work, and the scripting language used most in everyday life. Time to try a new shell for the future ahead.

WARNING: AI vibe-coded software.

Ideas stolen from many different languages. Source: github.com/aca/entish

LANG

Byte pipelines

# standard unix byte pipelines
$ ls *.mp4 | lines |> each { |f|        # | lines: stdout -> list of lines
    # extract audio
    ffmpeg -i $f -vn -c:a copy $f.m4a
}

Value pipeline (from elvish / rash)

# | carries stdout, |> carries values, nothing else crosses
$ ls | lines     # it's an entish value, not stdout
[ 'main.go' 'go.mod' ]
$ ls | lines |> len
2

# per-item logic on real values: files over 1000 bytes
# (bash: while read f; do [ "$(stat -c %s "$f")" -gt 1000 ] && ...)
$ ls | lines |> filter { |f| (num $(stat -c %s $f)) > 1000 }
[ 'big.bin' ]

# a list stays a list: no word splitting, names with spaces are safe
# (bash: mapfile -t, or find -print0 | xargs -0)
$ let mp4 = ls | lines |> filter { |f| $f != 'big.bin' }
$ ls -1 ...$mp4
a b.mp4
c.mp4

# with no arg, lines reads stdin like cat, so a fn can take a pipe
$ fn eachl f { lines |> each $f }
$ ls *.mp4 | eachl { print "mp4: $it" }
mp4: a b.mp4
mp4: c.mp4

Functional, no loops

a |> f x y    ≡   f x y a

# a fn writes output and returns a value; each operator takes one
$ fn build { go build -o app .; 'app' }   # output to stdout, value 'app'
$ let bin = build                        # $( build ) would take the output

$ [1 2 3 4 5] |> filter { $it % 2 == 1 } |> map { $it * $it }
[1 9 25]

# recursion instead of loops
$ fn fact n { if $n <= 1 { 1 } else { $n * (fact ($n - 1)) } }
$ fact 5
120

Rational by default (from raku)

$ 0.1 + 0.2 == 0.3
$true

Multiline strings (from zig)

$ let name = "world"
$ let py =
    $\\name = "$name"
    \\print(f"hello {name}")
$ print $py | python3 -
hello world

EDITOR

  • Vim by default

History search

Ctrl-R searches command history with fzf-style queries. Enter puts the selection into your input, ready to edit or run.

Recent locations

Ctrl-D opens recent directories. Type to filter, then Enter to jump there.

FEATURES

  • async direnv integration

Async completion

Tab gets command completions from Fish in the background, including options and their descriptions. Press it again to cycle through matches; Enter puts the selected one in without running.
